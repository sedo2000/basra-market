# سوق البصرة | Basra Market

منصة تجارة محلية متعددة المتاجر لمحافظة البصرة، بواجهة ويب مستقلة قابلة للفتح أيضاً كتطبيق Telegram Mini App.

## النسخة الحالية
- واجهة عربية RTL ومتجاوبة مع الهاتف.
- أقسام ومتاجر ومنتجات تجريبية قابلة للبحث والتصفية.
- سلة مشتريات مع كميات وحساب الإجمالي.
- إتمام طلب تجريبي وحفظه في localStorage.
- نموذج اهتمام للتجار.
- تهيئة Telegram Web App SDK.
- مخطط PostgreSQL أولي في `supabase/schema.sql`.

## التشغيل
الموقع الحالي ثابت ولا يحتاج build: افتح `index.html` أو انشر المستودع على Vercel.

## مهم قبل الإنتاج
البيانات في هذه النسخة تجريبية ومحلية في المتصفح. لم يتم بعد تفعيل تسجيل الدخول أو حفظ الطلبات مركزياً. لا تستخدمها لمعالجة طلبات حقيقية قبل ربط Supabase، وتفعيل سياسات RLS، والتحقق من Telegram initData على الخادم، وإعادة حساب الأسعار والمخزون من قاعدة البيانات. لا تضع مفتاح Supabase service_role في الواجهة الأمامية.

## نطاق الخدمة
محافظة البصرة فقط. الدفع عند الاستلام في مرحلة الإطلاق الأولى. يدعم التصميم خيار توصيل المتجر أو مندوب المنصة ضمن مراحل التطوير التالية.
